Kentucky Cutups for PFF Ultimate

One button that builds a 50-play Kentucky cutup for any player and saves it to the matching position folder in your PFF Collection.

1 · Add the button (one time)

Kentucky CutupsKC Review Drag both buttons up onto your Chrome bookmarks bar.
Don't see the bar? Press Ctrl+Shift+B (Mac: ⌘+Shift+B).

If dragging doesn't work: copy the button code, right-click the bookmarks bar → Add page…, name it Kentucky Cutups (or KC Review), and paste the code into the URL box.

2 · Build a cutup

  1. Open ultimate.pff.com and sign in as usual.
  2. Click Kentucky Cutups on your bookmarks bar. A panel opens on the right.
  3. Type First name, Last name, School. Leave Position on Use his PFF position, or pick one. Use + Add another position to build more than one.
  4. Click Build cutup. If several players match, pick the right one.
  5. About 10 seconds later the playlist is saved in that position's folder as POS_Last_First_School_#Jersey, with a link to open it and a link to review it.

3 · Review a build (quality control)

  1. On Ultimate, click KC Review (or Review builds at the top of the Kentucky Cutups panel).
  2. Every Kentucky cutup in your Collection is listed by position (Quarterbacks → Safeties), newest first, with the date and time it was created and who built it. Use the dropdown to show one position, or search by name or school. Click one.
  3. You get the full breakdown, cutup by cutup: each play's band (best / worst / recent / ranked), PFF grade, date, opponent (P4 marked), situation, his role, the play, the result, and a ✓ if it fits that cutup's rule.
  4. The top line checks the whole build: best vs. worst count, games used, average grade, any play that breaks its rule, and whether a rebuild with today's data would pick the same 50.
  5. Copy table for Sheets copies the whole breakdown so you can paste it into a spreadsheet to mark up.

What it does

Finds his playsEvery 2026 snap PFF has for him (tick 2025 to include last season), straight from Ultimate under your own login. No API key, no CSV download.
Builds the 50Kentucky plan for the position: 41 position plays, 5 Negative Plays, 4 vs. Top Competition. No repeats; best plays outnumber worst; max 3 per game; RB zone, gap and short-yardage plays are handoffs only; Pass Pro uses snaps where he engages; Routes & Targets puts targets first.
Saves itPlaylist named POS_Last_First_School (e.g. RB_Baxter_CJ_Kentucky), in cutup order, notes list the breakdown. It goes in the shared position folder (Quarterbacks … Safeties). A rebuild gets a dated name and never overwrites.
Short cutupsIf he doesn't have enough plays of a type, the panel shows which cutup came up short.

The buttons load the latest version every time they are clicked, so rule changes reach everyone automatically. No re-install needed.

Works in Chrome or Edge on a computer. Each coach uses their own PFF sign-in; the button never stores passwords or keys.
